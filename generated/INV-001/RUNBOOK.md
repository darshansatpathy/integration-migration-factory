## Cutover

1. Run `imf regress --flow INV-001 --bus kafka`; every difference must be listed in `accepted_differences.yaml`.
2. Run both platforms in parallel for a full business cycle, the Kafka path delivering to a shadow path, and compare each day's files with `imf compare --flow INV-001 --legacy <legacy output> --new <shadow output>`.
3. Switch ERP to the Kafka output. Keep the legacy flow deployed but unscheduled.
4. Decommission the legacy flow after one more cycle without incidents.

## Rollback

Re-enable the legacy schedule; the Kafka path holds no state that the legacy flow needs.
